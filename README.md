# Supermarket Sales Dashboard

An interactive Microsoft Excel dashboard analyzing supermarket sales performance.

## Project Overview

This project uses supermarket sales data to analyze revenue, gross income, product-line performance, branch performance, payment methods, and customer behavior.

The raw data was cleaned and prepared before creating the Excel dashboard and analytical views.

## Tools

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Data cleaning
- Data visualization


## Dashboard

The Excel dashboard provides interactive analysis of:

- Revenue and gross income trends
- Sales by product line
- Transactions by day of week
- Transactions by hour
- Payment methods
- Branch performance

## Files

- `Supermarket Sales Dashboard.xlsx` — Excel working data and interactive dashboard


## Dataset

The dataset was sourced from Kaggle and used for educational and portfolio purposes.

## Project Purpose

This project demonstrates practical skills in data cleaning, data analysis, Excel dashboard development, and data visualization.
